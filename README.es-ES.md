

# tlab-indicators

Este repositorio contiene todos los indicadores utilizados en https://cryptotrading-hub.com.

Puedes clonar este repositorio para crear nuevos indicadores. Lo mismo también se puede hacer en https://cryptotrading-hub.com. Ambos lugares ofrecen soporte completo para el autocompletado de código y snippets. La única ventaja de usar el editor de VS Code es poder utilizar tus atajos personalizados.
